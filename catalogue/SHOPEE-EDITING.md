# สินค้า Shopee ในเว็บ Brewtanist

## แก้ข้อมูล
Pages CMS → brewtanist/brewtanist.github.io → branch main → **08 · สินค้าจาก Shopee**

หมวด 08 เก็บรายการที่พบในหน้าร้าน Shopee พร้อมชื่อ คำอธิบาย หมวด รูปจริง และการแสดง/ซ่อนสินค้า ส่วน House Blend สามตัวอ่านชื่อ รายละเอียด และรูปจากหมวด 03 เดิม เพื่อไม่ให้แก้ข้อมูลซ้ำสองที่

อย่าใส่รูปเมล็ดกาแฟแทนแคปซูลหรือชุดของขวัญ รูปที่ยังไม่มีให้เว้นว่าง ระบบจะใช้การ์ดตัวอักษร ไม่สร้างบรรจุภัณฑ์สมมติขึ้นมา รูปจริงที่ใส่ต้องเป็น JPG/PNG/WebP ในคลัง brewtanist/assets และใส่คำอธิบายรูปด้วย

## สถานะข้อมูล
เก็บ 17 รายการจากหน้าร้านสาธารณะที่เครื่องมืออ่านได้: House Blend 3, Single Origin 6, แคปซูล 3, Drip Bag 1, ชุดของขวัญ 2, อุปกรณ์และของใช้ 2

ข้อมูลที่อ่านได้เป็น snapshot เก่า ไม่ใช่การยืนยันรายการขายปัจจุบัน ไม่ได้เชื่อม Shopee API และยังไม่ซิงก์ราคา สต็อก หรือออเดอร์ ไม่แสดงราคา คะแนนรีวิว จำนวนขาย หรือคำว่าพร้อมส่งจาก snapshot ปุ่มซื้อใช้ Shop ID และ Item ID ที่พบ ไม่ใช่ผลทดสอบการชำระเงินจริง

## การเผยแพร่
โค้ดและหมวดแก้สินค้าอยู่ใน main แล้ว แต่ catalogue ยังไม่ถูกเผยแพร่บน GitHub Pages และไม่ถือว่า Render ถูกสร้างเพียงเพราะผู้ใช้ติดตั้งแอป ต้องมี URL ปลายทางที่ตรวจได้จริงก่อนตั้ง catalogue_url ในหมวด 07 ห้ามใช้ rawcdn.githack เป็นลิงก์ถาวรของลูกค้า

ลิงก์ตรวจงานและ Artwork อยู่ใน LATEST-SHOPEE.md ลิงก์เฉพาะรุ่นจะไม่เปลี่ยนตาม Save ครั้งถัดไป

## Artwork ชุดแรก
มีภาพแบนเนอร์ 1920×900 และภาพสี่เหลี่ยม 1080×1080 ใช้ภาพ Render House Blend เดิม ไม่วาดแพ็กใหม่ ทั้งสองภาพอยู่ใน qa/artwork-house-wide.png และ qa/artwork-house-square.png ส่วนไฟล์จัดวางที่แก้ต่อได้อยู่ที่ catalogue/review/artwork.html

ภาพรายสินค้าสำหรับ 14 รายการที่เพิ่มยังไม่ได้ยืนยัน ควรตรวจรายการที่ยังขายอยู่และรูปตรง SKU ก่อนใช้ชุดแคตตาล็อกประชาสัมพันธ์เต็มรูปแบบ
