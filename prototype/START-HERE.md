## แก้ข้อความและเก็บใน GitHub

เปิด https://app.pagescms.org/ แล้วลงชื่อด้วย GitHub บัญชี `pumplcrs-hub` เลือกองค์กร `brewtanist` และ repo `brewtanist.github.io`

เลือก branch **`preview/brewtanist-lab-20261108`** แล้วเปิดเมนู **ร่างเว็บใหม่ · แก้ข้อความ**

แก้หัวเรื่อง คำแนะนำหน้าแรก ข้อความส่วนเลือกกาแฟกลับบ้าน และคำอธิบาย Mr. Plantman / Mr. Ozmo / Ms. Lazybug แล้วกด **Save** ข้อความจะถูกบันทึกที่ `prototype/copy.th.json` ใน GitHub ไม่ใช่เก็บเฉพาะเครื่อง

Save จะเริ่มตรวจข้อมูลและสร้างตัวอย่างใหม่ เมื่อผลตรวจผ่าน หน้าตัวอย่างล่าสุดด้านบนจะมีลิงก์รุ่นใหม่ ถ้าตรวจไม่ผ่าน ให้เปิดผลตรวจใน GitHub Actions เพื่อดูจุดที่ต้องแก้ รุ่นก่อนหน้าที่ผ่านแล้วยังอยู่

## แยกสองหน้าแก้ไข

**Pages CMS ใน branch นี้**: เก็บข้อความร่างลง GitHub มีประวัติการแก้ไข คำอธิบายสินค้าจะไม่เปลี่ยนระดับคั่ว Tasting notes หรือกฎแนะนำโดยอัตโนมัติ

**Content Studio ในเว็บตัวอย่าง**: ทดลองเปลี่ยนข้อความและรูป เห็นผลด้านข้าง แต่ยังเก็บเฉพาะเบราว์เซอร์ ไม่ซิงก์กลับ Pages CMS หรือ GitHub ส่งออก JSON เก็บได้ ถ้ามีร่างในเครื่องอยู่ ข้อความนั้นอาจทับการแสดงข้อความจาก GitHub ให้ส่งออกเก็บก่อนคืนค่า หรือเปิดตัวอย่างในหน้าต่างส่วนตัวเพื่อเทียบ

## ขอบเขตของรอบนี้

เปิดให้เก็บข้อความร่างออนไลน์ก่อน ยังไม่ได้เพิ่มระบบอัปโหลดรูปร่างผ่าน Pages CMS ของ branch นี้ ราคา ขนาด ตัวเลือกการบด แหล่งปลูก และลิงก์สินค้ารายตัวยังรอข้อมูลจริง

branch `main` คือเว็บร้านเดิม อย่าเลือก main เมื่อต้องการแก้ร่าง และอย่ากด Merge ของ Pull Request #1 เพื่อทดลองดูเว็บ ไม่มีการตั้ง branch protection หรือระบบอนุมัติบังคับเพิ่มในรอบนี้ การแยก branch ช่วยแยกงาน ไม่ได้ห้ามผู้มีสิทธิ์ไปแก้ main เอง

การล็อกอิน GitHub ไม่ได้ยืนยันว่า Pages CMS มีสิทธิ์ในองค์กรแล้ว หากไม่พบ repo ให้ติดตั้ง/อนุญาตแอป Pages CMS เฉพาะ `brewtanist.github.io` ผ่านหน้าแอป ห้ามส่งรหัสผ่านหรือ Token ในแชท

repo นี้เป็น Public ข้อความและไฟล์ที่บันทึกมองเห็นได้สาธารณะ แม้ Preview จะใส่ noindex ห้ามใส่ข้อมูลลูกค้า รหัสผ่าน เอกสารภายใน หรือข้อมูลที่ยังไม่ต้องการเปิดเผย

## ก่อนเผยแพร่จริง

ต้องตรวจข้อมูลสินค้าและกฎ Coffee Finder เลือก Hosting สำหรับแคตตาล็อก และทดสอบการแก้ผ่านบัญชีเจ้าของก่อน รอบนี้ไม่มี Checkout ไม่มีการรับเงิน และไม่มีการเปลี่ยนลิงก์ใน Google หรือ Social

เอกสารอ้างอิงการตั้งค่า: https://pagescms.org/docs/configuration/ และ https://pagescms.org/docs/quick-start/
